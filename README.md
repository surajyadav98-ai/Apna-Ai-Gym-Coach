# Apna AI Gym Coach

An AI-powered fitness coaching application built with Python to support exercise guidance and workout tracking.

## Features
- Exercise pose estimation
- Workout repetition counting
- Workout guidance
- AI-based coaching feedback
- Voice-based feedback

## Tech Stack
- Python
- Streamlit
- Computer Vision
- AI/ML

## Run Locally

Install the dependencies:

```bash
pip install -r "Main App/requirements.txt"
```

Start the application:

```bash
streamlit run "Main App/main.py"
```
